Building a 54-module global eLearning catalog

The five-day opening program needed a course library people could finish before they traveled. I built it in-house.

RoleCourse planning and hands-on production
ChallengeThe company needed online courses before it could shorten live training
What I didBuilt the catalog in-house and continue to produce each course
Result54 modules now serve teams in 5 languages. Building them in-house avoided an estimated six-figure vendor cost.

The challenge

Shorter store training depended on a solid eLearning library. We didn’t have one. Teams needed the same basic instruction before they arrived for live training.

An agency would take time to learn the product and cost more than we could justify. We didn’t have an in-house studio or a course developer, so I built the process myself.

My role

I planned the catalog and built the workflow. I set the intake and review process, then handled each LMS release.

I still produce the courses myself. I write the scripts and film the lessons. I record the voiceover, edit in DaVinci Resolve, and build the final course in the LMS. This setup lets me update a course as soon as the work changes.

I handle each step, so updates don’t sit in a vendor queue.

The approach

I run the work like a small in-house studio.

Build each course from start to finish

I turn a work need into a script, then film and edit the lesson. After review, I build the course in the LMS and publish it.

Use AI voiceover where it saves time

I tested ElevenLabs voice cloning and added it to the workflow. When a script changes, I can update narration in five languages without booking new studio time for every version.

Connect each course to the opening program

Each module covers knowledge learners need before arrival. That keeps the live days open for coached practice.

  • I built and maintain 54 modules in-house.

  • The courses now reach teams in five languages.
